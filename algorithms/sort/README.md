# Sort algorithms

## The sorting problem.
Given a sequence of n numbers <a1, a2, ..., an> as input, we need a permutation(reordering) <a11, a22, ..., ann> such that a11<=a22<=...<=ann

Sort algorithms were invented to solve the sorting problem. Based on factors but not limited to the following 

* number of items to be sorted
* extend to which the input is already sorted
* possible restrictions on the items values
* coputer architecture,
we decide which sorting algorithms to use in an application
