# Algorithms.

## About this directory

In this directory, we explore algorithms, starting from studying existing algorithms, algorithm design patterns(divide and conquer, greedy algorithms, dynamic programming, backtracking, etc) through to the process of designing algorithms and proving them correct, using these muscles to solve algorithms problems.

## What an algorithms is and why it was invented

An algorithms is a well defined set of computational procedures for transforming inputs to output.

Algorithms were invented when a group of Mathematicians sad together, trying to define a set of procedures for solving all set of mathematical problems, such that anyone could follow these steps and solve problems even without deep understanding of the subject matter.

It came to realization as it was pointed out by ... that not all problems had a clear step by step procedure for solving them. This prompted for a whole field of research called algorithms, the birth rock of Computer Science.

## Correctness of algorithm

An algorith is said to be correct if it halt and gives the correct output for every input. An incorrect algorithms may not halt or even when it halt, may not give the expected output for a given input.

## Efficiency of an algorithm

Two things(time and space) defines algorithm efficiency. There is a tradeoff between this two since optimizing for one affects the other, depending on the circumstance, we choose which to sacrifice for the other. In general, the idea is to strike the right balance. This efficiency is measured using a mathematical tool called the big O notation. This measures how the execution of an algorithms grows as the input grows.
